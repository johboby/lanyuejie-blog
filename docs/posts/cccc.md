# From Satellites to Forecasts: 遥感气象AI研究选题完全指南
## <span id="为什么你需要这张研究地图">为什么你需要这张研究地图</span>
> 遥感气象AI在2026年已经不是"拿个U-Net跑个数据集"那么简单了。它是一条从**数据获取→图像增强→时空建模→预报应用→气候评估**的完整研究链路——选题时只看方法新不新、不看链条位置，你的课题要么算力烧不起，要么审稿人一句"novelty不足"直接拒稿。
> **这篇文章给你四个候选方向的全景拆解：每个方向的任务定义、方法谱系、数据集、评估体系、切入点、天坑清单。读完你知道自己适合哪个方向，第一步该做什么。**
### 先说结论：你是谁，就选哪个方向
| 你的情况                       | 推荐方向                | 理由                           |
| ------------------------------ | ----------------------- | ------------------------------ |
| 计算机视觉背景，想快速出成果   | **方向一（生成/增强）** | 与CV方法同构，数据可小规模实验 |
| 有一定深度学习功底，想做方法论 | **方向二（时空建模）**  | 方法谱系完整，改进空间大       |
| 气候/气象科班出身，算力有限    | **方向三（CMIP6比较）** | CPU集群即可，拼的是气候学功底  |
| 想做贴近业务、落地感强的应用   | **方向四（临近预报）**  | 有清晰基准，行业需求明确       |
| 想发顶刊、能调动大算力         | 方向一/二 + 物理约束    | 生成式+物理一致性是当前主战场  |
> 一个残酷事实：**降水是所有地学变量里最难啃的骨头**——非负、长尾、间歇性、大量零值（0膨胀分布）。四个方向里有三个绕不开它。选它，风险与回报同在。



> **四个方向不是并列关系，是一条链。** 方向二是方法核心，方向一/四是它的两个应用出口，方向三是它的气候学对照组。跳层选题的后果：只做方法不落地 → 被问"so what"；只做应用不懂方法 → 被问"novelty where"。

## <span id="方向一遥感图像生成增强">方向一：遥感图像生成/增强</span>
### 一句话定位
> 用生成模型（扩散/GAN）让卫星图像**更清晰（超分）、更完整（去云修复）、更多（数据增强）**——本质是把CV的生成技术搬到物理约束极强的地球观测数据上。
### 任务拆解
| 子任务                   | 输入 → 输出             | 典型场景                         | 难度 |
| ------------------------ | ----------------------- | -------------------------------- | ---- |
| **超分辨率/降尺度**      | 低分辨率场 → 高分辨率场 | ERA5 SST(0.25°)→1km、降水降尺度  | ⭐⭐⭐  |
| **去云修复(Inpainting)** | 云遮挡图 → 无云图       | Sentinel-2地表修复、云图缺测填补 | ⭐⭐⭐  |
| **图像生成/增强**        | 噪声/条件 → 合成场      | 极端样本增强、反事实情景生成     | ⭐⭐⭐⭐ |
| **跨模态转换**           | A传感器 → B传感器       | 红外↔可见光、雷达↔雨量计风格迁移 | ⭐⭐⭐  |
### 技术路线：GAN vs Diffusion（2026年格局）
| 维度           | GAN系（ESRGAN/pix2pix改造） | 扩散系（SR3/LDM/ResShift改造） |
| -------------- | --------------------------- | ------------------------------ |
| 训练稳定性     | 需精心调参，易崩            | 稳定，目标函数清晰             |
| 推理速度       | 快（单次前向）              | 慢（多步采样），可用蒸馏缓解   |
| 样本多样性     | 差（易mode collapse）       | 好（可采样多个解）             |
| 极端事件重建   | 偏保守                      | 偏激进（可能"幻觉"）           |
| 物理约束嵌入   | 困难（对抗目标）            | 方便（可加在损失/引导中）      |
| **2026年推荐** | 基线/对照用                 | **主力路线**                   |
> 2026年的共识：**扩散模型已是遥感生成的主流**（SR3 [17] 之后大量工作验证），但气象场景的扩散模型必须加物理约束，否则审稿人第一个问题就是"生成的降水场物理上可信吗？"
### 数据集清单
| 数据                         | 内容                          | 分辨率            | 获取                           |
| ---------------------------- | ----------------------------- | ----------------- | ------------------------------ |
| ERA5 [11]                    | 全球再分析（SST/降水/云量等） | 0.25°，逐小时     | Copernicus CDS / AWS           |
| MODIS LST/SST                | 地表/海表温度                 | 1km，逐日         | NASA LAADS / GEE               |
| Sentinel-2                   | 多光谱地表                    | 10-60m，5天       | Copernicus / GEE               |
| Himawari-8/9、GOES-16、FY-4B | 静止卫星云图                  | 0.5-2km，10分钟级 | JAXA / NOAA / 国家卫星气象中心 |
| IMERG [14]                   | 卫星降水                      | 0.1°，30min       | NASA GES DISC / GEE            |
| OISST/OSTIA                  | 海表温度分析场                | 0.25°，逐日       | NOAA / CMEMS                   |
### 评估：为什么PSNR/SSIM会骗你

核心矛盾：生成模型的"锐度"与"保真度"不可兼得
MSE/PSNR最优解 = 条件均值 → 奖励模糊 → "糊成一团的高分"
GAN锐度 → 细节漂亮 → 可能是幻觉（不忠于真值）
2026年合格论文的评估套餐（缺一被审稿人追问）：
① 像素级：PSNR / SSIM（报，但只作参考）
② 感知级：LPIPS / FID
③ 结构级：功率谱密度（谱斜率匹配）
④ 物理级：下采样一致性（生成场降回低分辨率≈输入）
          分位数-分位数图（Q-Q图，极端分位数偏差）
          面积平均守恒（降水总量不漂移）
⑤ 极值级：P99/P99.9相对误差、极端事件命中率
```
### 推荐切入点
```
入门级：ERA5 SST（月平均）→ 0.05°超分
  ✓ 数据小（单变量2D场）
  ✓ 物理约束简单（海温平滑连续，无0膨胀问题）
  ✓ 可直接和统计降尺度（双线性/分位数映射）对比
进阶级：卫星云图去云修复（多时相 vs 单帧生成对比）
  ✓ 云检测用s2cloudless/Fmask现成工具
  ✓ 天然有"干净真值"（无云时刻）做监督
高阶：极值感知的降水降尺度（扩散+物理约束）
  ✓ 直击长尾分布痛点
  ✓ 顶刊口味：保真-锐度权衡+物理一致性双贡献
```
### 本方向天坑
| 坑 | 症状 | 正确做法 |
|---|---|---|
| 只报PSNR/SSIM | 模糊图拿高分 | 加谱分析+极值指标 |
| 无物理约束的扩散 | 生成负降水值 | 损失加守恒项/软约束引导 |
| 训练测试集时空重叠 | 泄漏，指标虚高 | 严格按年份切分 |
| 用模糊指标选模型 | 越选越糊 | 像素指标+感知指标+物理指标三权分立 |

## <span id="方向二气象时空序列建模">方向二：气象时空序列建模</span>
### 一句话定位
> 研究"**时空场序列**"的通用建模方法——给定过去N帧，预测/生成未来M帧——是四个方向的方法论心脏，方向一的增强结果和方向四的预报应用都吃这套能力。
### 三种任务（别混为一谈）
| 任务 | 输入 → 输出 | 例子 | 评估哲学 |
|---|---|---|---|
| **确定性预测** | 历史帧 → 未来帧（单解） | 温度场预报 | 逐点误差（MSE/MAE） |
| **概率性生成** | 历史帧 → 未来帧（多解分布） | 降水集合预报 | CRPS/分位数/极值 |
| **时空插补** | 缺测场 → 完整场 | 雷达拼图缺测填补 | 掩码区误差 |
### 方法谱系演进（2015→2026）
```
2015  ConvLSTM [3]           递归+卷积，开山之作，降水nowcasting
  ↓
2017  PredRNN [4]            时空记忆解耦（MIM），时空梯子
      TrajGRU               可变形连接，对抗运动
  ↓
2018  PredRNN++ / E3D-LSTM   记忆增强、3D卷积
  ↓
2020  PhyDNet [22]           物理约束分支（平流近似解耦）
      WeatherBench [15]      数据驱动中期预报基准确立
  ↓
2022  SimVP [5]              纯CNN，"简单打败复杂"
      SwinLSTM              Transformer进入时空预测
  ↓
2022-2023 Earthformer [6]    3D时空Transformer
      FourCastNet [7] / Pangu [8] / GraphCast [9]   AI中期预报三巨头
      DiffSTG [23]           扩散模型进入时空生成
  ↓
2024-2026 NowcastNet [2] / PreDiff [18] / Aurora [10]
      ── 生成式+物理约束成为主旋律，基础模型时代开启
```
### 基准数据集（从易到难）
| 数据集 | 内容 | 规模 | 定位 |
|---|---|---|---|
| Moving MNIST | 合成数字轨迹 | 10K样本 | 方法调试沙盒 |
| TaxiBJ | 北京出租车流量 | 2万+帧 | 时空预测入门 |
| SEVIR [16] | 雷达+卫星事件切片 | 38k+事件 | 遥感nowcasting标准基准 |
| HKO-7 | 香港雷达回波 | 8k+序列 | 降水外推经典集 |
| ERA5（自建切片） | 任意变量任意区域 | 自定 | **自留地，创新空间大** |
| WeatherBench2 | 全球中期预报 | TB级 | 对标大模型需大算力 |
### 核心难题：模糊 vs 幻觉（本方向的灵魂问题）
```
确定性模型（MSE训练）
  → 未来本质多模态（云的演化分岔）
  → MSE最优解 = 所有可能的平均
  → 输出模糊 → 极值系统性低估 → FVD差
生成式模型（GAN/扩散）
  → 采样出单条锐利轨迹
  → 但哪条对？错了没有惩罚信号
  → 极值可能幻觉 → 单次命中不可靠
2026年的解法光谱：
① 集合采样（扩散采N条 → 报概率）→ 评估用CRPS
② 物理条件引导（平流/动力约束注入扩散过程）[2]
③ 混合损失（MSE兜底 + 感知/对抗项提锐度）
④ 分位数回归（直接学分位数而非均值）
```
> **选这个方向，你必须能在一页PPT里讲清楚"模糊-幻觉权衡"**，这是所有时空生成论文的审稿核心战场。
### 推荐切入点
```
入门级：ERA5单变量（2m温度）区域时空预测
  ✓ ConvLSTM/SimVP/简单U-Net三模型对比即可成文
  ✓ 变量平滑，MSE指标够用，绕开降水难题
进阶级：云量/降水的概率时空预测（扩散 vs 判别式对比）
  ✓ 直面多模态问题
  ✓ CRPS+CSI+FVD全套评估是加分项
高阶：物理约束的时空扩散（守恒律/平流方程嵌入）
  ✓ 与CV方法的本质差异点，审稿人最爱
```

## <span id="方向三地球系统模型比较cmip6-vs-观测">方向三：地球系统模型比较（CMIP6 vs 观测）</span>
### 一句话定位
> 用观测/再分析数据给CMIP6气候模式"打分"——在某个区域、某个变量上量化**偏差**和**趋势**，是四个方向里**最不需要GPU、最依赖气候学功底**的选择。
### 研究设计模板（一张表定生死）
```
研究 = 区域 × 变量 × 观测基准 × 模式子集 × 分析维度 × 情景/时段
示例组装：
  区域：东亚季风区（或青藏高原/地中海/西非）
  变量：降水（pr）
  观测：GPCP（月）+ IMERG（日，仅2000后）
  模式：CMIP6 historical + SSP2-4.5/SSP5-8.5，取10-20个模式成员
  维度：气候态偏差 + 季节循环 + 年际变率 + 极端指标 + 趋势
  时段：历史基准期1995-2014，未来分期2030-2050 / 2080-2100
### 数据清单
| 类别     | 数据                      | 关键参数                       | 备注                     |
| -------- | ------------------------- | ------------------------------ | ------------------------ |
| 模式     | CMIP6 [12]                | ~100+模式，historical + 5个SSP | ESGF / AWS镜像下载       |
| 再分析   | ERA5 [11]                 | 0.25°，逐小时，1940至今        | 作为"观测代理"需声明局限 |
| 降水观测 | GPCP                      | 2.5°，月，1979至今             | 长序列月尺度金标准       |
| 降水观测 | IMERG [14]                | 0.1°，30min，2000.6至今        | 高分辨率但序列短         |
| 降水观测 | CRU / GPCC                | 0.5°，月                       | 陆地台站为主             |
| 温度观测 | HadCRUT5 / NOAAGlobalTemp | 网格月平均                     | 全球趋势基准             |
### 工具链（2026年标准配置）
| 工具                 | 用途                                    |
| -------------------- | --------------------------------------- |
| **xarray + dask**    | NetCDF/Zarr惰性计算，超大文件不爆内存   |
| **xesmf / xESMF**    | 重网格（regrid），模式↔观测网格对齐     |
| **cdo / nco**        | 命令行快速气候态/时间统计               |
| **ESMValTool [19]**  | CMIP评估专用pipeline，内置指标+引用格式 |
| **extremes / xclim** | ETCCDI极端指标（Rx1day/CDD/SDII…）计算  |
### 分析方法清单（按论文常见度排序）
| 分析       | 方法                                   | 回答什么问题                  |
| ---------- | -------------------------------------- | ----------------------------- |
| 气候态偏差 | 均值差（模式−观测）、空间偏差图        | 模式在该区域系统性偏湿/偏干？ |
| 季节循环   | 逐月 climatologies 对比                | 季风进退时间对不对？          |
| 年际变率   | 相关系数（如与ENSO指数）、标准差       | 变率幅度被高估/低估？         |
| 趋势       | 线性趋势 + Mann-Kendall显著性          | 变暖/变湿趋势在情景间的分叉   |
| 极端事件   | ETCCDI指标偏差、归一化偏差图           | 极端降水强度模式可信吗？      |
| 综合评价   | Taylor图（相关+标准差+RMSE一图定乾坤） | 哪些模式表现最好？            |
| 不确定性   | 模式间散布、模式独立性讨论             | 集合均值可信度                |
### 数据处理天坑清单（每一条都是血的教训）

① 单位：CMIP6降水标准单位是 kg m-2 s-1
   → 忘乘86400换成 mm/day，结果全错（最常见低级错误）
② 日历：部分模式用 360_day / noleap 日历
   → 与标准日历对齐必须显式处理，xarray会静默错位
③ 网格：模式各自原生网格（高斯网格/规则网格）
   → 比较前必须统一 regrid，且要做面积加权（cos纬度）
④ 成员：同一模式多个 realization（r1i1p1f1 / r2i1p1f1…）
   → "模式间独立"假设不成立；一个模式只取一个成员
   或做成员平均，否则多成员模式权重虚高
⑤ 基准期：观测与模式历史期重叠要声明
   → 常用 1995-2014 或 1985-2014
⑥ ERA5不是观测：再分析含模式同化成分
   → 评极端降水时ERA5本身有偏差，最好双观测源互证
```
### 推荐切入点
```
入门级：CMIP6多模式某区域年降水/温度偏差+Taylor图
  ✓ ESMValTool现成recipe改造，2-3个月成文
  ✓ 适合作为硕士论文第一章
进阶级：极端降水指标（Rx1day/CDD）的模式评估
  ✓ 直击"模式最弱项"，问题天然成立
  ✓ 可加IMERG做日尺度高分辨验证
高阶：偏差成因归因（环流分解/水汽收支分解）
  ✓ 从"有多大偏差"升级到"为什么偏"
  ✓ 需要动力气候学功底，顶刊路线
```

## <span id="方向四短时临近预报替代研究">方向四：短时临近预报替代研究</span>
### 一句话定位
> Nowcasting = 未来0-3小时降水/雷达回波外推——从光流法到深度学习再到生成式模型，这是**基准最清晰、业务需求最明确、方法论演进最完整**的应用方向。
### 方法演进三代史
| 代际 | 代表方法 | 核心思想 | 致命伤 |
|---|---|---|---|
| 传统 | 光流法、STEPS（集成） [24] | 运动场估计+外推+随机扰动 | 无法生成新回波、演变能力弱 |
| 第一代DL | ConvLSTM [3]、TrajGRU | 序列学习端到端外推 | MSE训练→输出模糊 |
| 第二代DL | **DGMR** [1]（GAN）、MetNet系列 [25] | 生成模型出锐利预报 | 极值可能幻觉、难加物理 |
| 第三代DL | **NowcastNet** [2]（扩散+演化）、**PreDiff** [18]（物理约束扩散） | 物理机理+生成模型融合 | 训练复杂、算力需求高 |
### 代表模型速查
| 模型 | 来源 | 机制 | 关键贡献 |
|---|---|---|---|
| DGMR [1] | DeepMind, Nature 2021 | 条件GAN | 首证生成式nowcasting超越传统方法 |
| NowcastNet [2] | 清华/华为， Nature 2023 | 扩散+演化式物理条件 | 降水动力演化方程融入生成过程 |
| PreDiff [18] | 2024 | 潜空间扩散+物理约束 | 训练中显式施加守恒约束 |
| MetNet-3 [25] | Google | 神经网络概率预报 | 业务级多源输入（雷达+卫星） |
| Pangu [8] / GraphCast [9] | 华为/DeepMind | 3D Transformer/GNN | 中期预报（注意：非nowcasting赛道） |
### 数据集
| 数据 | 内容 | 时空规格 | 适用 |
|---|---|---|---|
| SEVIR [16] | 美国雷达+卫星事件集 | 384/48px切片，事件级 | 标准基准，入门首选 |
| HKO-7 | 香港雷达回波 | 480px，5min间隔，120min预报 | 降水外推经典 |
| MRMS | 美国多雷达拼图 | ~1km，2min | 大规模训练 |
| 本地雷达拼图 | 各国气象局 | 视数据授权 | **自留地，易出增量** |
| ERA5切片 | 任意变量 | 0.25°，逐小时 | 方法预研/无雷达数据时的替代 [4] |
| GPCP/IMERG | 降水观测 | 见方向三表 | 验证/驱动数据 |
### 评估体系（这套指标不会=外行）
```
① 分级指标（对每个降水强度阈值分别算）：
   CSI  = 命中 / (命中 + 漏报 + 空报)     ← 行业标准
   HSS  = Heidke技巧评分（扣除随机命中）
   POD / FAR = 命中率 / 空报率
   关键惯例：报告 CSI@{1, 2, 5, 10, 20+ mm/h} 多阈值曲线
   极值阈值（>20mm/h）的表现才是论文卖点
② 概率指标（生成式/集合预报）：
   CRPS = 概率积分变换的距离度量       ← 集合质量金标准
③ 生成质量指标：
   FVD  = 视频域FID                    ← 评"像不像真的雷达动画"
④ 老三样仅作参考：PSNR/SSIM（会奖励模糊预报）
```
### 本方向核心矛盾（与方向二同源）
```
业务真相：漏报强对流 = 灾难；空报 = 狼来了
   → 不同阈值上POD/FAR的偏好不同
   → 单一指标选模型必然翻车
2026年审稿标配实验矩阵：
  你的方法 × {光流, ConvLSTM基线, DGMR类基线} × {CSI多阈值, CRPS, FVD}
  × 多个数据集（至少SEVIR + 一个本地/区域数据）
```
### 推荐切入点
```
入门级：SEVIR上复现SimVP/PredRNN + 光流基线对比
  ✓ 数据集自带DataLoader生态，工程量小
  ✓ 补一个"多阈值CSI+误差随时效衰减曲线"即成小论文
进阶级：ERA5驱动的方法预研 → 迁移到雷达
  ✓ 用ERA5降水做0.25°的"低配版nowcasting"
  ✓ 提出新结构后用SEVIR/HKO-7验证
高阶：物理约束扩散的nowcasting（跟随NowcastNet/PreDiff路线）
  ✓ 极值命中率 + 物理一致性双卖点
  ✓ 需要至少4×A100级算力
```

## <span id="常见研究反模式">常见研究反模式</span>
| 反模式 | 症状 | 后果 | 正确做法 |
|---|---|---|---|
| **只报PSNR/SSIM** | 生成结果"高分但糊" | 被一枪毙 | 三权分立：像素+感知+物理 |
| **MSE训生成模型** | 输出模糊还怪数据 | 极值全漏 | 扩散/GAN + 概率评估 |
| **无面积加权平均** | 全球均值悄悄错 | 数字不可信 | cos(纬度)加权 |
| **忘记单位换算** | 降水小86400倍 | 全文作废 | 数据加载层统一规范化 |
| **时间切分泄漏** | 训练测试集年份交错 | 指标虚高被质疑 | 按年/按季严格切分 |
| **单阈值CSI报结果** | 只报1mm/h这种"送分题" | 被评"回避难点" | 多阈值曲线+极值档 |
| **ERA5当万能真值** | 拿它评极端降水 | 系统性误导 | 双观测源互证+声明局限 |
| **模式成员当独立样本** | 一个模式取5个成员 | 统计显著性虚高 | 模式级聚合或独立处理 |
| **无光流基线** | 只跟DL方法比 | 缺传统对照 | STEPS/光流法必进对比表 |
| **大而全不聚焦** | "全球+全年+全变量" | 每个都浅 | 一区域一变量做深 |

## <span id="faq">FAQ</span>
### 1. 四个方向到底选哪个？
按三要素决策：背景、算力、目标。CS背景+有GPU → 方向一/二/四（方法创新空间大，可投ML会议）；大气/地理科班+算力有限 → 方向三（CPU集群即可，拼气候学设计，投气候期刊最对口）；想快速毕业 → 方向三或"方向四复现+小改进"；想冲顶刊 → 方向二+物理约束的生成式建模，这是2023年NowcastNet [2] 登Nature后延续至今的主战场。实在纠结：先做Phase 1（数据基础），哪个方向的数据让你愿意天天看，就选哪个——热情决定续航。
### 2. 需要多少算力？没有GPU怎么办？
方向三几乎不需要GPU（xarray+dask的CPU集群足够，笔记本都能跑区域月尺度分析）。方向一/二入门实验1-4张消费级显卡够用（ERA5单变量区域切片是小数据）。真正吃算力的是：大规模扩散模型训练（方向一/四的进阶路线，4×A100起步）和全球中期大模型对标（FourCastNet [7]/Pangu [8] 级别，不建议研究生个人硬刚）。策略：用"区域+单变量+低分辨率预研"控制算力，方法验证后说清楚扩展路径即可。
### 3. ERA5能当"真值"用吗？
要分场景。作为**模式输入/再分析研究**：可以，ERA5 [11] 是目前最广泛使用的再分析，质量公认。作为**评估观测的代理**：可以但有条件声明——评温度、环流等大尺度量时偏差可控；评**极端降水**时ERA5本身有明显局限（同化系统对对流尺度降水刻画不足），必须与GPCP/IMERG/台站数据互证 [11][14]。论文里直接写"以ERA5为参考"而不讨论其局限，是审稿人容易抓住的硬伤。方向三里CMIP6 vs ERA5的结论，最好加一句"再分析不确定性"的敏感性检验。
### 4. 2026年做生成，GAN还是扩散？
扩散。2021年DGMR [1] 用GAN登Nature后，GAN路线在nowcasting/生成领域的红利期基本结束；2023年NowcastNet [2] 用扩散+物理再登Nature，确立了"生成式+物理约束"的新范式。GAN在2026年的合理定位是**基线**（复现用，对比用）。但注意扩散的两个代价：采样慢（需要蒸馏/少步采样技术弥补）和训练贵。如果你的卖点是"物理一致性"而非"模型结构"，扩散的损失函数可微性使物理约束更容易嵌入 [18]，这是GAN做不到的。
### 5. 气象AI会不会被大模型（Aurora/盘古等）卷死？
不会，赛道分层了。大模型（GraphCast [9]、Pangu [8]、Aurora [10]）占据的是**全球中期预报**赛道，那是工业界大算力的地盘。研究生机会在它们覆盖不到的地方：① 区域高分辨率（大模型0.25°级，对流尺度1km级仍是空白）；② 极端事件与长尾分布（大模型整体指标好看，极值表现仍是公开弱点）；③ 物理可解释与约束（黑盒之外的机理融合）；④ 降尺度与偏差校正（方向一/三，与预报大模型是互补而非竞争）；⑤ 临近预报（0-3小时，赛道独立）。一句话：别跟大模型比"全球平均"，去做它做不好的"局部极端"。
### 6. 没有气象背景，要补什么？反过来，没有深度学习背景呢？
CS背景补三门课的地学部分：① 气象动力学基础（理解平流、对流、为什么降水难——推荐先读"为什么预报降水比预报温度难一个数量级"的科普文献）；② 数据格式与规范（GRIB/NetCDF、CF约定、CMIP命名规则——这是工程必修）；③ 目标变量的物理特性（降水的0膨胀长尾、SST的平滑连续性，直接决定你的模型设计）。反过来，大气背景补：① PyTorch工程能力（数据管道>模型结构）；② 深度学习基础（至少到扩散模型原理）；③ 生成模型评估哲学（为什么MSE会骗你）。共同必修：统计学假设检验（方向三的命根子）和可复现研究（Git+配置文件+随机种子管理）。

## <span id="写在最后">写在最后</span>
### 三个核心认知
**1. 四个方向是一条链，不是一个菜单。** 方向二是方法心脏，一/四是应用出口，三是气候学对照。单点选题必然被问"上下游"，选题时就想清楚你在链条上的位置和邻居。
**2. 评估体系比模型结构更能决定论文命运。** PSNR/SSIM糊弄、单阈值CSI回避极值、ERA5当万能真值——2026年的审稿人对这些套路零容忍。先建指标全家桶，再训模型。
**3. 降水是最难也最值钱的变量。** 非负、长尾、间歇、多模态——所有生成的坑它全占了。绕开它做温度/海温是稳健路线，直面它做极值生成是高风险高回报路线。清楚自己在哪条路上。
```
