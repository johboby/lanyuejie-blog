国家数据局在 2026 年 3 月正式给 Token 起了中文名叫"词元"，还给了官方定义："词元是大模型处理信息的最小单元，具有智能时代可计量、可定价、可交易的特征。"这个定义看似朴素，但它背后是一个产业逻辑的根本转移——算力市场的价值锚点，已经从训练侧的 FLOPS 和 GPU 卡数，切换到了推理侧的 Token 产出。这篇文章把散落的数据串起来，尽量把这件事讲清楚。

## 先看一组数据

把国家数据局、信通院、Gartner 的三份数据放在一起看，能拼出一条完整的曲线。

国家数据局：中国日均词元调用量从 2024 年初的约 1000 亿，飙升至 2025 年底的 100 万亿，到 2026 年 3 月进一步提升至 140 万亿。两年增长超过 1000 倍。第三方机构的周度监测数据印证了同样的趋势，周度 Token 消耗从 2.1T 涨到 24.5T，2026 年以来周度增长 280%。

Gartner 的预测给出了一条结构性变化，2026 年全球推理支出将达 233 亿美元，首次超过 190 亿美元的训练支出，占 AI IaaS 总支出的 55%，2027 年这个比例将升至 59%。

信通院《词元（Token）经济发展研究报告（2026 年）》预计，2026 年推理算力占 AI 算力总负载的比重将达到 70.5%。截至 2026 年 6 月底，全国智能算力总规模达 2185 EFLOPS（FP16），2025 年全国累计建成 42 个万卡级智算集群。

这三组数据指向同一个判断，AI 基础设施的价值重心正在从"训练谁更强"转向"推理谁更便宜、更快、更稳"。

## 为什么是现在

过去两年，行业叙事的主线是训练，哪家模型参数量更大、谁的算力集群更大。2026 年这个叙事被推理侧的数据彻底改写。原因不是 Token 本身变便宜了，而是 Token 消耗的结构变了。

传统 AI 对话里，一次请求对应一次模型推理，消耗几百到几千 Token，用户问完即走，算力消耗是离散、短周期的。但智能体（Agent）的工作方式完全不同。一个 Agent 完成一个任务，需要规划、搜索、调工具、执行、验证，循环几十轮甚至上百轮。输入侧 Token 膨胀是指数级的——一次 Agent 调用，上下文可以比输出长几十到几百倍。

这就是为什么 2026 年"词元"从技术文档里的晦涩概念，变成了上下游每一方都要精打细算的战略资源。Token 不再是被藏在模型 API 文档里的计量单位，而是直接出现在客户的月度账单上。

## 词元经济的四层结构

信通院把词元经济拆成四层产业链，这个框架值得展开。

**设施层：词元的供给底座。** 这一层的逻辑正在从"峰值算力最大化"转向"每瓦 Token 产出最大化"。硬件选型、集群架构、调度系统都要围绕推理而非训练来设计。异构协同、推理芯片与推理引擎的耦合、网络互联与调度，构成新的技术栈。

**生产层：词元的"含金量"。** 不同场景的 Token 价值密度差异巨大。消费级闲聊、娱乐问答，约 0.01 美元/百万 Token；产业级的药物研发、金融量化、精密代码生成，价值可达 1000 美元/百万 Token。100 倍的差距，意味着"卖 Token 的生意"在不同场景下商业模型完全不同。

**分发层：词元的调度中枢。** OpenRouter 最新数据显示，9 月下旬全球 AI 大模型总调用量为 146 万亿 Token/周，环比增长 13.18%。中国大模型周调用量连续二十二周超过美国，稳居全球首位。但这里有一个常见的认知误区——把 Hugging Face 权重下载量和 OpenRouter Token 调用量混同为"出海成绩"，两者的商业含金量天差地别。

**应用层：词元的价值出口。** 按智能产出计费，是词元经济最核心的商业模式。客户买的不是 Token 数量，是业务任务完成结果。路由优化减少无效调用和重试，Token 消耗下降，任务价值反而在提升。

## 定价正在重构

过去两年是 Token 价格战。2026 年出现了一个转折。

信通院《大模型词元服务性能监测报告（2026 年）》显示，词元服务呈现量价齐升态势，国内归一化均价从 2025 年下半年的 6.8 元/百万 Token 涨到 13.46 元，涨幅接近一倍，但调用量增长了 3 倍。国外价格仍显著高于国内，2026 年以来发布的典型模型平均归一价格约为 117.8 元。

价格上涨的同时，各家大厂也在调整计费模式。腾讯云、阿里云、百度云纷纷涨价，智谱、字节跳动、MiniMax、月之暗面也上调了 API 价格。Anthropic 把 Claude Enterprise 从固定月费改为按算力消耗收费。

这不是简单的"涨价"，而是计费粒度在变细，加入 cache、batch 等条目，打破了"按 GPU 时长"的传统计量体系。客户过去购买整张 GPU 卡，成本固定且存在闲置浪费；现在按 Token 付费，成本与业务用量完全挂钩，门槛降低的同时，重度用户也面临"成本雪崩"的可能——月度 Token 费用可达数十万元甚至数百万元。

## 一个容易被忽略的细节：中文分词

词元化过程里有一个常被忽略的环节。英文单词有空格天然分割，中文是连续的字符流，分词拆解复杂度显著高于英文。这意味着同样一段内容，中文消耗的 Token 数往往多于英文，直接推高推理成本。分词效率因此成为国产大模型提升核心竞争力的一个隐性抓手。这个细节在讨论"中国大模型出海"时经常被遗漏，但它直接影响 Token 计费的公平性。

## 写在最后

词元经济不是一个新名词，而是一个真实的产业拐点。它标志着 AI 从"模型能力竞赛"进入"推理服务规模化"阶段，算力投资的评估标准从"峰值算力"变成"每瓦 Token 产出"，商业模式从"卖资源"变成"卖智能结果"。

对产业参与者来说，现在最该回答的问题不是"我的模型参数多少"，而是"我的推理端每瓦 Token 产出多少，每百万 Token 成本多少，在什么场景下价值密度最高"。这三个问题的答案，决定了一个 AI 公司在 2027 年能不能活下来。
